# モックの利用状況の分析

`aws-ml-enablement-workshop/yourwork` をカレントディレクトリとして実行します。以下のパスはすべてここからの相対パスです。

1. `product/construction/plan.md` から、モックのデプロイに使ったプロファイル名とデプロイ先リージョンを読みます。無ければユーザーに尋ねます。
2. `template/ANALYTICS_GUIDE.md` を読み、その手順（ロググループの特定、クエリの実行、必ず除くもの、レシピ、答え方）に従って集計し、日本語で答えます。

手順とクエリは `template/ANALYTICS_GUIDE.md` にあり、このファイルには複製していません。AWS のリソースは作成・変更せず、読み取りのコマンドだけを使います。
